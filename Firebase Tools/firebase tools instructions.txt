1. download node.js (if not downloaded already) - https://nodejs.org/en/download
2. in the cmd run: npm install -g firebase-tools
3. in the cmd run: firebase --version (verification the installation succeeded - should be 14.12.0)
4. in the cmd run: firebase login (and login with a valid user with permissions)
5. create a folder to init the firestore-functions.
in the cmd:
	mkdir my-firebase-functions
	cd my-firebase-functions
6. init: firebase init functions
7. you will get options to choose:
	7.1 it will ask you to associate the project — select your existing Firebase project
	7.2 JavaScript 
	7.3 ESLint - no
	7.4 install dependencies - yes
8. update index.js file to the existing one
9. run in the folder via cmd: firebase deploy --only functions (make sure the user has permissions)
